КАК ЗАГРУЗИТЬ НА GITHUB
1. Распакуйте архив.
2. Создайте публичный репозиторий GitHub.
3. Загрузите в корень репозитория три файла: index.html, style.css, app.js.
4. В Settings -> Pages выберите Deploy from a branch, ветку main и папку / (root).
5. Нажмите Save.

ПЕРЕД ТЕСТОМ FIREBASE
1. Создайте проект и Realtime Database в Firebase.
2. Зарегистрируйте Web App.
3. Скопируйте конфигурацию Firebase в начало app.js вместо YOUR_...
4. Включите правила доступа только для временного теста. Не оставляйте публичную запись открытой для реального запуска.
