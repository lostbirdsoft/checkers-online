ШАШКИ ONLINE — ОБНОВЛЁННАЯ ВЕРСИЯ

В архиве:
- index.html — интерфейс игры;
- style.css — оформление;
- app.js — логика русских шашек и синхронизация Firebase;
- FIREBASE_ROOM_CLEANUP.gs — отдельный код автоматической очистки старых комнат;
- README.txt — инструкция.

ЧТО РЕАЛИЗОВАНО
- Автоматическое назначение первого и второго игрока по Telegram ID.
- Имена и фамилии игроков из Telegram.
- Автоматический старт, когда в комнате два игрока.
- Русские шашки 8×8:
  - простые шашки ходят вперёд по диагонали;
  - простые шашки бьют вперёд и назад;
  - взятие обязательно;
  - при серии взятий нужно завершить всю цепочку;
  - дамка ходит и бьёт по диагонали на любое расстояние;
  - при достижении последнего ряда шашка становится дамкой;
  - проверяется отсутствие шашек и доступных ходов у соперника.
- Предложение ничьей и согласие второго игрока.
- Сдача.
- Реванш: новая партия начнётся, когда оба игрока нажмут кнопку «Реванш».
- Автоматическая ничья при повторении позиции три раза или 80 полуходах без взятия/превращения в дамку.

ВАЖНО О ПРАВИЛАХ
Это реализация русских шашек с практическим автоматическим правилом ничьей (80 полуходов без взятия или превращения). Это не замена официальному турнирному регламенту. В частности, для публичных турниров отдельно согласуйте регламент ничьих.

КАК ОБНОВИТЬ САЙТ
1. Распакуйте архив.
2. Откройте репозиторий https://github.com/lostbirdsoft/checkers-online
3. Замените в корне репозитория файлы index.html, style.css и app.js.
4. Нажмите Commit changes.
5. Подождите 1–3 минуты, пока GitHub Pages обновит сайт.
6. В Telegram-группе отправьте /play, чтобы получить новую комнату.
7. Откройте приглашение с двух разных аккаунтов Telegram. Один и тот же Telegram-аккаунт на двух устройствах будет считаться одним игроком.

FIREBASE
Используется существующий проект lostbird-checkers и существующая база данных.
Новый код хранит состояние партии в:
rooms/ID_КОМНАТЫ/game
Игроки остаются в:
rooms/ID_КОМНАТЫ/players
Метаданные комнаты остаются в:
rooms/ID_КОМНАТЫ/info

Текущие открытые правила Firebase подходят только для прототипа. До публичного запуска обязательно нужны проверка Telegram initData на сервере, аутентификация и серверная проверка ходов. Сейчас браузерные клиенты сами вычисляют разрешённые ходы, поэтому открытые правила не защищают от намеренной подмены данных.

АВТООЧИСТКА КОМНАТ
1. Откройте существующий проект Google Apps Script бота.
2. Нажмите + рядом с Files и выберите Script.
3. Назовите файл RoomCleanup.
4. Скопируйте туда весь код из FIREBASE_ROOM_CLEANUP.gs.
5. Нажмите Save.
6. В списке функций выберите installCheckersRoomCleanupTrigger и нажмите Run.
7. Подтвердите разрешения Google, если появится запрос.

После этого очистка будет запускаться каждый час:
- комнаты без второго игрока удаляются через 24 часа;
- завершённые партии удаляются через 1 час;
- активные, но заброшенные партии удаляются через 7 дней после последнего обновления.

Функция использует уже существующее свойство Script Properties:
FIREBASE_DATABASE_URL

Она удаляет всю ветку конкретной комнаты, включая игроков, ходы и метаданные.

ПРИМЕЧАНИЕ
Старые тестовые комнаты с полем last_move не переносятся в новую игровую систему. Для проверки создайте новую комнату командой /play.
