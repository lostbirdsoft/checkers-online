ИКОНКИ ИНТЕРФЕЙСА
=================
Положи сюда картинки с точно такими именами. Любой файл, которого нет, пропускается: на его месте
остаётся обычная эмодзи, как сейчас. Можно добавлять иконки по одной, остальное не сломается.

Формат: все файлы в ОДНОМ формате, по умолчанию PNG (расширение задаётся флагом UI_ICONS_EXT в app.js:
png, webp или svg). Фон прозрачный. Лучше всего SVG (чёткий на любом экране), из растровых PNG.
Размер PNG: квадрат 128 x 128 px (на экране иконка 20-32 px, запас нужен для телефонов с высокой плотностью).
Вес одной иконки: до 15 КБ. Стиль у всех один (одинаковая толщина линий, одинаковые отступы).
Размер на экране меняется флагом UI_ICON_SCALE в app.js (сейчас 1.25 от высоты текста).

Как включить/выключить: флаг UI_ICONS_ENABLED в app.js (false = только эмодзи, как раньше).
После добавления иконок обнови APK не нужно: файлы подтягиваются с сайта. Если иконка в приложении не
сменилась, закрой и открой приложение ещё раз (файлы кэшируются).
